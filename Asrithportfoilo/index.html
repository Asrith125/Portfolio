PROJECT 01 · AIIn development

NIRVAHAM AI

Plug in. Ask. No internet needed.

A personal AI assistant designed to run locally from a USB drive, with privacy and offline access at its core.

PythonLocal AIUSB portable
Project details

NIRVAHAM aims to load a locally stored language model and use the computer’s CPU, GPU, and RAM to generate responses. Internet access is optional for features that need it.

The project is in its initial development phase. Current work includes local model setup, the chat interface, connecting the desktop and browser interfaces, offline response testing, and exploring USB portability. The complete portable offline system is not yet finished or verified.

Future plans include Telugu and English support, document summaries, local file search, voice interaction, optional online information, user-controlled computer automation, and stronger privacy features.

PROJECT 03 · WEBWorking local prototype

SnapShare AI

Wedding photos, shared in one gallery.

A local-first wedding photo gallery for creating events, uploading and searching photos, downloading images, and copying a guest link. The current server runs on one computer, so links are not yet accessible from guests’ phones or other computers.

HTML · CSS · JavaScriptPythonSQLite
What works and what’s next

Photographers can create events with a date and venue; upload JPEG, PNG, and WebP photos up to 20 MB each; browse and search by filename; download photos; and copy a guest gallery link. Event data is stored in SQLite and photos stay on the computer running the app. The website shell can reopen offline after its first visit, but event data and photos still need the server.

Current limitation: the server listens only on the same computer, so guests cannot open the link from phones or other computers.

Next steps: add photographer accounts and access controls, secure HTTPS hosting, protected photo storage, and backups. QR codes, local-network sharing, cloud sync, and a mobile app are also planned. Any future face-based discovery would need consent and deletion controls.
